# 平台域规格条目

本文件是平台域（网关鉴权、端来源识别、账号与登录、内部调用、视频交付、AI 接入、接口契约）的唯一规格来源。规格条目只依据**已冻结的决策**编写：`engineering-plan.md` 15.2 的 D2/D4/D5/D8/D10 决策、AGENTS 的工程规则与产品文档中已确认的决策；不引用现状实现或存在矛盾的现状描述。

- 编号规则：`SPEC-{DOMAIN}-{NNN}`，三位序号只增不减，废弃条目保留编号并标记「已废弃」，不得复用。
- 状态取值：`未开始` / `进行中` / `已完成` / `已废弃`。
- 计划层级：L1 上线硬门槛、L2 业务闭环、L3 体验与运维、`上线后首批` 表示首版上线后第一批交付、`—` 表示无待办。
- 实现状态汇总见 `docs/project-status.md`。

### SPEC-PLAT-001 网关身份头剥离与注入

**来源**：engineering-plan 第 6 章、AGENTS 第一节高风险改动区。
**输入输出**：外部请求携带身份头进入网关 → 网关剥离客户端提供的身份头，校验凭证后注入可信身份头转发下游。
**验收标准**：客户端伪造的用户标识、角色与来源头一律被清除；未携带有效凭证访问受保护路径返回 40101；运营后台路径要求 ADMIN 或 OPS 角色，否则返回 40301；下游服务只信任网关注入的身份头，不自行解析客户端头。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-PLAT-002 端来源识别

**来源**：D2（分端能力）、D10（`source` 仅 `web/miniapp`）、审查结论 A1、计划 L2-1。
**输入输出**：请求进入网关 → 服务端判定来源端并写入身份上下文，登录会话记录来源。
**验收标准**：Web、小程序与运营后台三端来源可区分；来源由服务端按入口判定，不接受客户端自报；小程序请求的来源记为 `miniapp`，Web 为 `web`，后台为 `admin`；来源只用于能力边界与统计，不作为越权判定的唯一依据。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L2-1

### SPEC-PLAT-003 小程序登录与凭证防重放

**来源**：D2（小程序能力）、product-lifecycle 6.2。
**输入输出**：小程序 `wx.login` 的临时凭证 → 换取微信身份 → 老用户登录或新用户建号并绑定。
**验收标准**：临时凭证只能使用一次，重复使用返回 66001 且不创建新会话或新账号；功能开关关闭时返回 66003；微信侧失败或拒绝返回 66001，且不回显上游响应内容；会话密钥只保存在服务端；新用户在同一事务内自动授予 STUDENT 并写入绑定关系。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-PLAT-004 账号注销冷静期

**来源**：D8、product-lifecycle 6.2「注销」。
**输入输出**：用户申请注销 → 账号进入 7 天冷静期；冷静期内撤销 → 恢复为正常；到期人工确认 → 完成注销。
**验收标准**：申请后 7 天内可撤销并恢复为正常状态；存在进行中订单或退款时申请被拒并返回明确业务错误；冷静期内登录给出注销中提示且限制高风险操作；注销生效后法定交易记录保留且不可删除，个人信息匿名化，微信绑定解绑。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L1-7

### SPEC-PLAT-005 服务间内部调用鉴权

**来源**：engineering-plan 第 6 章、AGENTS 第一节高风险改动区。
**输入输出**：服务间调用 `/internal/**` → 校验共享内部令牌后放行。
**验收标准**：缺失或错误的内部令牌返回 40101；令牌比较使用常量时间实现；令牌无默认值，未配置时启动失败而不是静默关闭校验；外部请求无法经网关访问 `/internal/**`。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-PLAT-006 视频上传校验与交付

**来源**：D5（自建交付、服务端强制校验）。
**输入输出**：教师上传课时视频 → 服务端校验容器、编码、分辨率、时长、大小与完整性 → 通过后写入对象键，播放时签发短时效地址。
**验收标准**：非标准 MP4/H.264 文件拒收并返回 61003；超过大小上限拒收；校验失败不产生可发布课时；通过后记录对象键与时长，未通过校验的课时不能提交课程审核；播放地址由服务端签名且有效期受限。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L1-8

### SPEC-PLAT-007 AI 模型接入（BYO）

**来源**：D4（客户自配模型）。
**输入输出**：运营在后台配置 `base_url`、`api_key`、模型名、超时重试、日与月 token 上限与启用开关 → AI 服务按配置调用 OpenAI 兼容接口。
**验收标准**：代码中不写死任何供应商地址与平台密钥；`base_url` 必须为 HTTPS；`api_key` 密文存储且接口只回显掩码；未配置或校验失败时 AI 接口返回 AI 链路不可用错误（不得返回 500），前端隐藏 AI 入口；AI 不可用不影响交易、播放与学习进度；超出日/月配额时拒绝调用并告警。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：上线后首批

### SPEC-PLAT-008 统一响应与错误码分段

**来源**：AGENTS 11.4、engineering-plan 附录 A。
**输入输出**：任一接口的成功或失败 → 统一响应结构，失败携带错误码与消息。
**验收标准**：所有接口返回统一响应结构；错误码按 `4xxxx` 客户端/协议、`5xxxx` 服务端与依赖、`6xxxx` 业务分段，业务段第二位表示域（61 课程、62 交易、63 学习、64 互动、65 AI、66 小程序登录）；同一语义不跨段重复定义；参数校验失败返回 40001 而非 500；异常响应不包含堆栈或内部实现细节。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-PLAT-009 分页约定

**来源**：AGENTS 11.4、审查结论（`page/size` 与 `pageNum/pageSize` 冲突）。
**输入输出**：列表类接口接收 `pageNum`、`pageSize` → 返回当前页数据与总数。
**验收标准**：所有列表接口统一使用 `pageNum`、`pageSize`；默认值为 1 与 20，上限为 100；`pageNum` 小于 1 时归一为 1，`pageSize` 超过上限时按 100 截断而不是报错；响应包含实际生效的分页参数、总数与当前页记录。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—
