# 平台域规格索引

本文件只维护平台域条目的索引与状态；单条功能的详细规格（背景、场景、边界、未决问题）放在 `docs/specs/features/SPEC-PLAT-NNN/spec.md`。核心条目已展开详情（001 网关身份头与运营权限），其余保持索引层、不批量回填。

- 编号规则：`SPEC-{DOMAIN}-{NNN}`，三位序号只增不减；废弃条目保留编号并标记「已废弃」，不得复用。
- 状态取值：`未开始` / `进行中` / `已完成` / `已废弃`。
- 计划层级：L1 上线硬门槛、L2 业务闭环、L3 体验与运维、`上线后首批` 表示首版上线后第一批交付、`—` 表示无待办。
- 验收标准逐条编号为 `AC-1`、`AC-2`…，每条一句、可用「是/否」判定；本表只放摘要，完整表述在对应功能目录。
- 规格条目只依据已冻结的决策（D2/D4/D5/D8/D10、AGENTS 规则与已确认的产品决策）编写，不引用现状实现或存在矛盾的现状描述。
- 实现状态汇总见 `docs/project-status.md`。
