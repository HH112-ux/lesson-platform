## 2. 背景与目标

同一门课在不同状态、不同购买状态下必须返回不同结果：未上架的课不能被搜索引擎或匿名用户看到，已下架的课不能成为新用户的购买入口，但已购用户不能因为下架而失去已购买的内容。本条目冻结「匿名可浏览什么、什么状态返回 40401、谁可以越过下架限制」三条边界，试看播放的具体签名规则由学习域承接。

## 3. 范围

### 3.1 包含

- 公开接口 `GET /api/v1/courses`、`GET /api/v1/courses/{courseId}`、`GET /api/v1/courses/{courseId}/chapters` 的可见性判定。
- 匿名（未登录）访问的行为与不返回 `40101` 的范围。
- 已下架课程对持权益用户的放行。
- 逻辑删除课程的不可见。

### 3.2 范围外

- 播放凭证的签名与试看开关，见 SPEC-LEARN-003。
- 课程审核与上架动作，见 SPEC-COURSE-004。
- 搜索排序、推荐与埋点，本期不做。
- 运营后台与教师后台的课程列表，见 SPEC-COURSE-001 与 SPEC-COURSE-004。

## 4. 用户场景

| 编号 | 类型 | 场景 | 期望结果 |
|---|---|---|---|
| S-1 | 正常 | 匿名用户打开课程列表 | 只看到状态为已上架的课程 |
| S-2 | 正常 | 匿名用户打开已上架课程详情与目录 | 正常返回，`owned=false`，免费课时 `playable=true` |
| S-3 | 边界 | 匿名用户访问已下架课程详情 | 返回 `40401`，不泄露课程标题与价格 |
| S-4 | 正常 | 已购学员访问已被下架的课程 | 正常返回详情、目录，`owned=true`，可继续学习 |
| S-5 | 异常 | 任何人访问草稿或待审核课程 | 返回 `40401`，已购学员同样不可见 |
| S-6 | 异常 | 任何人访问已逻辑删除课程 | 返回 `40401`，列表与搜索均不出现 |

## 5. 验收标准

- AC-1：课程状态为 0 草稿或 1 待审核时，该课程不出现在 `GET /api/v1/courses` 结果中，详情与目录接口均返回 `40401`。
- AC-2：课程状态为 3 已下架且请求用户无该课程有效权益时，详情、目录接口返回 `40401`，列表接口不返回该课程。
- AC-3：课程状态为 3 已下架且请求用户在 `user_entitlement` 存在有效记录时，详情与目录接口正常返回，`owned=true`，章节中 `playable` 按已购计算。
- AC-4：课程被逻辑删除后，无论状态字段取值为何、无论请求用户是否持有权益，列表、详情与目录接口均不返回该课程，详情与目录返回 `40401`。

## 6. 边界与异常

| 编号 | 触发条件 | 系统表现 | 关联 AC |
|---|---|---|---|
| E-1 | 未登录访问公开详情、目录、列表 | 正常返回，不返回 `40101`，`owned=false` | AC-1 |
| E-2 | 未登录访问需登录的收藏、评论接口 | 返回 `40101`，与公开接口区分 | AC-1 |
| E-3 | 课程 id 不存在 | 返回 `40401`，与无权限下架课使用同一码，避免探测 | AC-2 |
| E-4 | 已下架课程且用户权益已被退款撤销 | 按无权益处理，返回 `40401` | AC-3 |
| E-5 | 课程状态在请求过程中被运营变更 | 以请求进入时读取的状态为准，单次响应不混用两种状态 | AC-1 |
| E-6 | 目录中课时全部被删除 | 详情仍可返回，目录为空数组，不返回 500 | AC-3 |
