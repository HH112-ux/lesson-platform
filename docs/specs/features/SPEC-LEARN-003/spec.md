## 2. 背景与目标

播放地址一旦直接下发，未购用户即可绕过下单与权益校验获取视频。本条目把播放能力收敛为「每次请求现签、短时有效」的凭证：访问判定只看 `user_entitlement` 与课时试看标记，签名有效期固定的同时允许在有效权益下反复获取。完成后，未购用户无法拿到付费课时凭证，试看能力可由服务端开关一键关闭，已下架课程对已购用户仍可学习。

## 3. 范围

### 3.1 包含

- `GET /api/v1/lessons/{lessonId}/play-token` 的访问判定与签名下发。
- 免费试看开关 `lp.learn.free-preview-enabled` 的作用范围与降级表现。
- 已上架 / 已下架课程在有无权益两种组合下的可见性。
- 签名有效期与重复获取规则。

### 3.2 范围外

- 课程详情与章节目录的公开可见性，见 SPEC-COURSE-007。
- 权益的发放与撤销，见 SPEC-LEARN-001 与 SPEC-LEARN-002。
- 视频上传校验与转码，见 SPEC-PLAT-006。
- 同一用户并发播放路数限制（`61004`），本期无对应条目，不做约定。

## 4. 用户场景

| 编号 | 类型 | 场景 | 期望结果 |
|---|---|---|---|
| S-1 | 正常 | 已购学员打开付费课时 | 返回带签名的 `playUrl`、`expiresIn=600`、`expiresAt` |
| S-2 | 正常 | 未购学员打开已上架课程的免费课时，开关为开 | 正常返回签名地址 |
| S-3 | 边界 | 未购学员打开已上架课程的付费课时 | 返回 `40302`，不返回任何地址 |
| S-4 | 异常 | 未购学员访问已下架课程的任何课时（含免费课时） | 返回 `40401`，优先于 `40302` 判定 |
| S-5 | 正常 | 已购学员访问已被运营下架的课程 | 正常取得签名地址，可继续学习 |
| S-6 | 边界 | 运营关闭试看开关后，未购学员请求免费课时 | 返回 `40302`，与付费课时一致 |

## 5. 验收标准

- AC-1：请求课时所属课程为已上架（`status=2`）且该课时 `is_free=0` 时，用户在 `user_entitlement` 无有效记录的请求返回 `40302`，响应体不含 `playUrl`。
- AC-2：`lp.learn.free-preview-enabled=false` 时，即使课时 `is_free=1` 且课程已上架，无有效权益的请求也返回 `40302`；该开关不改变已购用户的取签名结果。
- AC-3：请求课时所属课程状态为 0 草稿或 1 待审核时，无论用户是否持有权益、是否为免费课时，一律返回 `40401`。
- AC-4：请求课时所属课程状态为 3 已下架，且用户在 `user_entitlement` 存在该课程有效记录时，接口返回签名地址而不是 `40401`。
- AC-5：签名有效期默认 600 秒，响应 `expiresIn` 与 `expiresAt` 一致；有效权益用户在凭证过期后再次请求可取得新签名，不受次数限制。
- AC-6：请求课时所属课程状态为 3 已下架，且用户在 `user_entitlement` 不存在该课程有效记录时，无论课时 `is_free` 是否为 1、试看开关是否开启，一律返回 `40401`，优先于 `40302`。

## 6. 边界与异常

| 编号 | 触发条件 | 系统表现 | 关联 AC |
|---|---|---|---|
| E-1 | 未登录或凭证无效 | 网关返回 `40101`，不进入访问判定 | AC-1 |
| E-2 | 课时不存在或已逻辑删除 | 返回 `40401` | AC-3 |
| E-3 | 权益记录存在但已过期（`expire_at` 早于当前时间） | 按无权益处理，返回 `40302` | AC-1 |
| E-4 | 已下架课程且用户无权益，课时 `is_free=1` | 返回 `40401`，试看开关不能绕过下架规则 | AC-6 |
| E-5 | MinIO 凭据未配置或签名失败 | 返回 `50206`，禁止返回拼装的假地址 | AC-5 |
| E-6 | 开关热更新期间并发请求 | 以请求到达时读取到的开关值为准，单个请求内判定只做一次 | AC-2 |
