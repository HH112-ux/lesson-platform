# 课程域规格条目

本文件是课程域（建课、审核、上下架、展示与访问控制）的唯一规格来源。规格条目只依据**已冻结的决策**编写：`engineering-plan.md` 15.2 的 D 编号决策、2026-11-09 负责人拍板的五条口径，以及产品文档中已确认的决策；不引用现状实现或存在矛盾的现状描述。

- 编号规则：`SPEC-{DOMAIN}-{NNN}`，三位序号只增不减，废弃条目保留编号并标记「已废弃」，不得复用。
- 状态取值：`未开始` / `进行中` / `已完成` / `已废弃`。
- 计划层级：L1 上线硬门槛、L2 业务闭环、L3 体验与运维、`—` 表示无待办。
- 每条条目在实现完成时更新状态与「最后核对」日期；实现状态汇总见 `docs/project-status.md`。

### SPEC-COURSE-001 教师建课与课程归属

**来源**：D1（角色权限）、product-lifecycle 6.4「课程归属」。
**输入输出**：教师提交分类、标题、封面、详情、难度与拟定价 → 生成草稿课程，`owner_teacher_id` 为当前教师。
**验收标准**：仅 TEACHER 可建课，创建后状态为 0 且归属正确；非 TEACHER 建课返回 40301；对非本人课程执行任何写操作返回 40301。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-002 可编辑范围与改稿回退

**来源**：engineering-plan 2.3、product-lifecycle 6.4「草稿」。
**输入输出**：对状态 0/3 的课程与内容执行增删改 → 保存结果；编辑状态 3 的课程 → 状态回到 0。
**验收标准**：状态 0、3 可编辑；状态 1、2 的写操作被拒绝并返回状态冲突；编辑已下架课程后状态变为 0，必须重新提交审核。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-003 提交审核

**来源**：engineering-plan 2.3、product-lifecycle 6.4「待审核」、D5（视频约束）。
**输入输出**：状态 0/3 → 1；要求至少 1 个章节、至少 1 个含有效视频对象键且时长大于 0 的课时。
**验收标准**：内容不完整时提交被拒并指出缺失项；提交成功后课程只读，重复提交被拒；非本人课程提交返回 40301。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-004 运营审核、定价与首次上架

**来源**：D1、product-lifecycle 6.4「审核通过」「审核驳回」、2026-11-09 定价口径。
**输入输出**：运营对状态 1 的课程执行通过与定价（1→2）或驳回（1→0，审核意见 ≤300 字）→ 课程状态与最终价格更新，写入审核记录。
**验收标准**：通过与定价为同一动作，不产生「审核通过待上架」中间态；通过后学员端立即可见且价格等于运营确认价；驳回必须填写不超过 300 字的意见并回到草稿；非状态 1 的审核请求被拒；每次审核均可在审核记录中查到操作人、时间与前后状态。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-005 教师下架与再上架

**来源**：D1、product-lifecycle 6.4「下架与再上架」、审查结论 A3。
**输入输出**：教师对本人课程执行下架（2→3）与再上架（3→2）。
**验收标准**：教师可下架本人已上架课程；状态 3 且未发生内容变更的课程可直接再上架；已因编辑回到状态 0 的课程不得直接上架；非本人课程返回 40301。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L2-3

### SPEC-COURSE-006 运营强制下架

**来源**：product-lifecycle 6.4「运营可下架任意课程并填写原因」、审查结论 A4、计划 L2-5。
**输入输出**：运营对任意已上架课程执行强制下架 → 状态 2→3，记录原因与操作人。
**验收标准**：运营可下架任意已上架课程；原因必填且长度受限；动作写入统一审计；无对应权限码返回 40301。
**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L2-5

### SPEC-COURSE-007 公开展示与访问控制

**来源**：D2（能力边界）、product-lifecycle 6.3「可见范围」「异常状态」、engineering-plan 2.3。
**输入输出**：未登录或已登录用户请求课程列表、详情、目录 → 仅返回状态 2 且未删除的课程。
**验收标准**：状态 0/1 课程不出现在列表、搜索与详情，统一返回 40401；状态 3 课程对无有效权益用户返回 40401，对持有有效权益用户正常返回详情、目录与播放凭证；已删除课程不可见。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-008 内容结构与删除限制

**来源**：product-lifecycle 6.4「删除限制」、审查结论 C6。
**输入输出**：教师维护章节与课时（排序、标题、视频、时长）→ 目录更新；删除已产生订单的课时 → 拒绝。
**验收标准**：已上架课程不可修改或删除内容；已产生订单的课时删除返回 40901；删除章节时其下课时同步不可见；排序值必须为连续非负整数。
**状态**：进行中｜**最后核对**：2026-11-09｜**层级**：L2-3

### SPEC-COURSE-009 教师入驻审核

**来源**：product-lifecycle 6.4「入驻前置」、审查结论 A7、计划 L1-5。
**输入输出**：教师提交入驻资料 → 运营审核为通过/驳回（`audit_status` 0 待审／1 通过／2 驳回）→ 仅通过状态可建课。

**状态**：未开始｜**最后核对**：2026-11-09｜**层级**：L1-5

### SPEC-COURSE-010 展示字段与长度约束

**来源**：product-lifecycle 6.3「详情」、engineering-plan 4.3.2 字段定义。
**输入输出**：教师提交标题、副标题、描述、封面、难度、分类 → 保存并对外展示。
**验收标准**：标题 1–120 字符、副标题不超过 200 字符、封面上传地址必填、描述为长文本、难度取枚举值、分类必须存在；超限或缺失返回参数错误而非服务端异常。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-COURSE-011 定价口径

**来源**：D9（0 元课程）、product-lifecycle 6.4、2026-11-09 定价口径。
**输入输出**：教师建课或编辑草稿时提交拟定价 → 运营审核时确认或覆盖最终价 → 最终价随上架生效。
**验收标准**：教师可提交非负、最多两位小数的拟定价（允许 0 元）；运营审核时可覆盖；对外展示与下单均使用审核确认后的最终价；三位及以上小数被拒绝而非静默舍入。
**状态**：进行中｜**最后核对**：2026-11-09｜**层级**：L1-2
