# 学习域规格条目

本文件是学习域（权益、播放凭证、学习进度、完课判定）的唯一规格来源。规格条目只依据**已冻结的决策**编写：`engineering-plan.md` 15.2 的 D2/D5/D6/D7 决策、2026-11-09 负责人拍板的五条口径，以及产品文档中已确认的决策；不引用现状实现或存在矛盾的现状描述。

- 编号规则：`SPEC-{DOMAIN}-{NNN}`，三位序号只增不减，废弃条目保留编号并标记「已废弃」，不得复用。
- 状态取值：`未开始` / `进行中` / `已完成` / `已废弃`。
- 计划层级：L1 上线硬门槛、L2 业务闭环、L3 体验与运维、`—` 表示无待办。
- 实现状态汇总见 `docs/project-status.md`。

### SPEC-LEARN-001 权益发放与幂等

**来源**：D6（退款撤销权益）、D9（0 元订单）、engineering-plan 2.3。
**输入输出**：支付成功、0 元订单完成或运营授予 → 写入 `user_entitlement`；重复消息 → 不重复发放。
**验收标准**：同一用户同一课程只存在一条权益记录；重复发放幂等无副作用；退款撤销后迟到的支付发放在同一订单上不得恢复权益；重新购买可复用原记录并置为有效，不产生第二条记录。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-LEARN-002 退款后的权益撤销

**来源**：D6、engineering-plan 2.3。
**输入输出**：退款成功 → 权益置为失效，学习记录保留。
**验收标准**：撤销只改状态、不物理删除权益与学习记录；撤销后再访问课程按未购处理并返回 40302；同一退款重复撤销幂等；旧订单的撤销不得覆盖已发生的新购买。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-LEARN-003 播放凭证与访问控制

**来源**：D2、D5（签名 URL）、engineering-plan 5.6。
**输入输出**：已登录用户请求课时播放 → 短时效签名播放地址与过期时间。
**验收标准**：付费课时无有效权益返回 40302；免费试看受 `lp.learn.free-preview-enabled` 开关控制，关闭后一律校验权益；非已上架课程对无权益用户返回 40401，对持有有效权益的用户仍可正常学习；签名有效期默认 10 分钟，过期后可重新获取；响应只包含签名地址与到期时间，不暴露对象存储密钥。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-LEARN-004 进度上报与有效观看时长

**来源**：D7、engineering-plan 5.6「有效观看时长口径」。
**输入输出**：上报 `{lessonId, positionSeconds}` → 服务端计算本次可信增量、累计有效观看秒数、最大播放位置与完成态。
**验收标准**：不使用客户端上报的时间间隔，按服务端记录的间隔计算且单次增量不超过间隔 × 1.5；位置回退或重复上报同一位置不增加有效观看；间隔小于 5 秒或位置小于 2 秒的上报不计入；位置为负或超过课时时长返回 63001；最大播放位置只增不减且仅用于续播；完成态由服务端计算，客户端不能直接提交。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-LEARN-005 完课判定（双 90%）

**来源**：D7、2026-11-09 口径「完课按 D7 双 90% 严格执行」。
**输入输出**：课时累计有效观看秒数与播放位置 → 课程完成态。
**验收标准**：仅当有效观看时长 ≥ 课时时长的 90% **且**播放位置 ≥ 课时时长的 90% 时置为完成；拖动跳过时段不计入有效观看；完成态一旦置位不回退；客户端无法绕过任一条件将课时标记完成。
**状态**：进行中｜**最后核对**：2026-11-09｜**层级**：L1-6

### SPEC-LEARN-006 我的课程列表

**来源**：D2（跨端一致）、D6（退款后仍保留记录）、product-lifecycle F10。
**输入输出**：已登录用户分页查询本人权益 → 课程卡片（标题、封面、进度百分比、最近学习课时、是否已退款）。
**验收标准**：仅返回本人权益对应的课程；已退款课程保留在列表中并标记为已退款且不可进入学习；课程已不存在时跳过该条而非整页失败；进度百分比为已完成课时数除以在架课时数，四舍五入且封顶 100，课时数为 0 时为 0。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—

### SPEC-LEARN-008 退款准入进度汇总

**来源**：D6、SPEC-TRADE-008。
**输入输出**：交易域内部查询某用户在某课程的已完成课时数与在架课时数 → 完成百分比。
**验收标准**：只统计完成态为完成的课时；在架课时数为 0 时百分比为 0 且不得除零；课程不存在返回 40401；该查询只读，不修改任何进度数据；交易域查询失败时按失败关闭处理（50201），不得按 0 进度放行退款。
**状态**：已完成｜**最后核对**：2026-11-09｜**层级**：—
