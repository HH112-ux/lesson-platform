# Changelog

本文件记录用户与运维可感知的变更，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0] - 2026-11-06

首个可演示版本：教师建课、运营审核、学员购买与学习、退款闭环全部可跑通。

### Added

- 学员端 Web：课程列表、课程详情、下单、支付、我的课程、播放鉴权与进度回写。
- 教师工作台：创建课程、章节与课时，提交审核，查看自己的课程列表。
- 运营后台：审核课程并通过后上架。
- 微信小程序：课程浏览、课程详情、我的课程、播放页面；暂不含支付。
- 退款闭环：已支付订单可发起全额退款，退款成功后权益失效、学习记录保留、我的课程标记「已退款」、播放接口拒绝访问。
- 权益发放 outbox：失败自动重试与指数退避，超过上限进入死信，运营可重放。
- 监控：trade-service 暴露 `/actuator/prometheus`，提供 `entitlement_outbox_pending` 与 `entitlement_outbox_failed` 两个指标。
- 本地验收：`scripts/verify-all.sh` 一条命令完成起栈、冒烟、outbox 故障演练、退款演练与数据清理；另有独立演练脚本可单独执行。

### Changed

- 退款采用权益软失效（`user_entitlement.status = 1`），不物理删除权益与学习记录；已退款用户再次访问课程按未购处理，再次购买可重新生效。
- actuator 仅暴露 `health`、`info`、`prometheus`，且只在服务端口提供，不经过网关对外转发。

### Fixed

- 重复的支付回调不会重复发放权益；同一笔订单重复退款返回原退款单，不会重复出款或反复置位权益。
- 退款金额超过实付或部分退款被拒绝，避免出现负差额与账实不符。
- 小程序播放被拒时提示「该课程已退款，学习权限已收回」，与 Web 端文案一致。
